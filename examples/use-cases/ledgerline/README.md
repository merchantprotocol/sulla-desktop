# Ledgerline

Close the month without the scramble.

## Setup
Put a ledger export in Files and optionally add bank, payment processor, payroll-total, and receipt exports. A read-only ledger integration is optional.

## Use and customize
Ask for a month-end close packet or enable the monthly routine. Customize the target month, reconciliation tolerances, and output folder in `SKILL.md`. Journal entries and ledger changes are never posted automatically.
