# Homecoming

**Listing:** Homecoming — *Win back customers who've gone quiet* — Find customers past their normal buying rhythm and draft thoughtful win-back sequences without sending them.

Homecoming turns an order CSV into a ranked, evidence-backed list of lapsed customers and three-touch drafts. A monthly workflow repeats the read-only analysis.

## Setup
No integration is required: upload an order export to Files. Optionally connect a storefront, CRM, ledger, or email provider through `vault`; reads are optional and email remains draft-only.

## Use and customize
Run the skill with a named export. Confirm recipients and any offer before drafting. Customize the cadence, ranking fields, and voice; never remove the complaint stop rule or send gate.
