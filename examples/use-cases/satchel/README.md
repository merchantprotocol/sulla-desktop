# Satchel

Satchel organizes closed-book exports, receipts, and contractor-payment evidence into a packet an accountant can review. It is not tax advice and does not file or send anything.

## Setup
Connect a ledger and optional Drive read access, or upload P&L, payment, and receipt exports to Files. Provide country, tax year, entity type, and currency.

## Use and customize
Ask for a tax packet, quarterly estimate preparation, or a 1099 candidate list. Customize the accountant questions and output folder in Files. Review every assumption with the accountant.
