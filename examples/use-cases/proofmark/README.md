# Proofmark

**Listing:** Proofmark — *Check an analysis before anyone else sees it* — Recompute key results, expose weak assumptions, and issue a clear share-or-revise verdict.

Proofmark reviews methodology, data quality, calculations, bias, charts, narrative claims, and reproducibility. Its validation report distinguishes verified results from checks that could not be run.

## Setup
No integration is required when the analysis and source data are in Files or pasted into the conversation. A vault-backed read-only PostgreSQL integration is optional for checking SQL-derived results.

## Use and customize
Provide the analysis, source data, definitions, queries or formulas, time range, timezone, and intended audience. Customize the risk thresholds or required spot-check count for your team, but keep the three-level verdict and evidence for every finding. Proofmark never shares the reviewed analysis without human approval.
