# Coldbrew

Write cold outreach drafts that sound human and stay grounded in evidence.

## Setup
Optional: connect read-only prospect research or email draft access through vault. Pasted context and uploaded Files are complete fallbacks. Sending is never automatic.

## Use and customize
Ask for a first touch or follow-up sequence and provide the audience, offer, proof, signal, and CTA. Customize the voice and compliance placeholders in `SKILL.md`.
