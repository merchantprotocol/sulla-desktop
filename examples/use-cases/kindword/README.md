# Kindword

Read public reviews, identify themes, and draft replies for human review. Nothing posts.

## Setup
- Public browser access or a CSV/export in Files is enough.
- Optional: connect Google Business Profile read access through vault.
- Add a voice profile in memory or Files for consistent drafts.

## Use and customize
Ask “draft replies to this week's reviews.” Set review sources, date range, response length, tone, and output folder. Review each draft before posting; the workflow is intentionally draft-only.
