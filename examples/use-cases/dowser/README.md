# Dowser

Find look-alike prospects worth calling from customer evidence and public research.

## Setup
Upload a customer CSV/XLSX to a managed Files folder. No integration is required; a CRM or lead-data vault integration is optional and writes remain approval-gated.

## Use and customize
Ask for “look-alike prospects” and specify geography, sector, count, or scoring preferences. Customize the scoring rubric in `SKILL.md`.
