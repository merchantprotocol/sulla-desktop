# Spyglass

**Listing:** Spyglass — *Profile a competitor from their URL and watch for changes* — Build a source-linked competitor snapshot and flag meaningful website or pricing changes over time.

Spyglass researches public pages with the Sulla browser, stores comparable snapshots in Files, and repeats the read-only check weekly.

## Setup
No integration is required. Provide public competitor URLs and an existing Files folder for snapshots. The workflow reads only public pages and does not publish or contact anyone.

## Use and customize
Ask for a quick scan or deep profile. Customize the profile dimensions, comparison axes, and weekly schedule in `routine.yaml`. Keep raw URLs beside conclusions so changes can be audited.
