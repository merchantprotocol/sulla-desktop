# Google review response drafts

Prepare thoughtful, human-reviewable responses to recent Google reviews without posting them.

## Instructions

1. Use the connected browser or review integration with read-only permission to read the requested business's reviews. Do not sign in with credentials pasted into chat and do not open a write endpoint.
2. For each selected review, capture only its rating, date, public reviewer name, and minimum necessary text. Do not infer private facts.
3. Draft a concise response in the business's requested voice: acknowledge the specific experience, thank the reviewer, and invite offline follow-up for complaints. Never promise compensation or disclose customer information.
4. Return the review link, draft response, and any uncertainty. Label every item `DRAFT — review before posting`; never submit, reply, edit, or publish anything.
