# Parry

Answer sales objections with proof from your own wins, not generic rebuttals.

## Setup
Install the pack, then add approved objection patterns and customer evidence to its memory files. Keep deal-specific material in Files. No integration is required; pasted objections and uploaded notes work.

## Use and customize
Ask “how should I answer this objection?” and paste the exact words. Edit the pack only with evidence the owner has approved. Sending and CRM writes are gated.
