# Crawlspace

Audit whether a public site is readable, indexable, and accurately citable by search and AI assistants.

## Setup
- No integration is required; provide a public URL.
- Optional: connect Search Console for owner-provided metrics. It is not required for the crawl.
- Store reports and copy-ready fixes in Files.

## Use and customize
Ask “audit my site's AI visibility.” Set URLs, customer queries, bot policy, and output folder. The included function checks deterministic HTML/robots signals. It never edits DNS, CMS content, or catalogs.

The folder also includes `function.yaml` and `main.py` for the offline HTML/robots signal checks.
