# Graft

Graft converts a permissively licensed public skill into a Sulla use case. It inventories the real source, chooses the smallest extension kinds, replaces foreign tool assumptions with verified Sulla commands, preserves licensing, and validates the draft.

## Setup
No integration is required. GitHub access is optional for private sources; public sources can be fetched normally. Marketplace publication is intentionally excluded.

## Use and customize
Ask Sulla to “convert this public skill into a Sulla use case” and give it the source URL. Customize the conversion checklist in `SKILL.md`, but keep the provenance, validation, and human-approval gates.
