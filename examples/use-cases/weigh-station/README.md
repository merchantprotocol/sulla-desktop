# Weigh Station

Weigh Station compares vendors on total cost, risk, performance, fit, and leverage before procurement sign-off.

## Setup
No integration is required. Upload proposals or contracts, paste figures, or use a CSV. Browser research of public pricing pages is optional. Files is used for source-linked reports.

## Use and customize
Ask for a new-vendor, renewal, or side-by-side review. Customize cost categories, risk appetite, scoring weights, and approval thresholds. It never signs, purchases, or contacts a vendor.
