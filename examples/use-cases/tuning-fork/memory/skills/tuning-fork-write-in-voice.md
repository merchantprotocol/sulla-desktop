**When:** Use the installed voice profile for drafting or revision. If the profile has no evidence for the requested channel, say so and use the closest variant conservatively.

**Do:**
1. Identify the audience, channel, purpose, facts, and desired action.
2. Read the Tuning Fork subject traits, vocabulary, rhythm, structure, and channel variants.
3. Draft for meaning first, then apply the voice traits that fit this channel.
4. Check every factual claim against supplied material. Mark gaps instead of inventing proof.
5. Compare the result against the voice profile and revise the three largest mismatches.
6. Return the draft plus a one-line voice check. Keep it a draft unless the human explicitly approves sending or posting.

**Don't:** Do not turn the profile into catchphrases, exaggerate quirks, or force every channel into one tone.
