# Tuning Fork

Tuning Fork learns a brand voice from real owner-approved examples and installs an editable memory pack that other drafting skills can reuse.

## Setup
No integration is required. Public website reading and a connected Drive are optional; pasted text and Files are supported fallbacks.

## Use and customize
Ask Sulla to discover your brand voice from selected examples, or to check a draft against it. Customize the installed subject and skill under the Tuning Fork use case, then bump `memory/manifest.json` before syncing the pack.
