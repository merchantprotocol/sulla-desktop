# Daily inbox triage brief

Turn a busy inbox into a short, decision-ready morning brief without sending or deleting anything.

## When to use this skill

Use when the owner asks for an inbox triage, morning email brief, or unread-message summary.

## Instructions

1. Use the connected email provider's read/search tools to inspect messages received since the last brief. Never send, archive, delete, or change labels.
2. Group messages into: urgent reply, waiting on someone else, receipts/records, and low-priority reading.
3. For each urgent item, include sender, subject, why it matters, and a one-line suggested next action. Quote only the minimum necessary text.
4. End with counts by group and ask before any outward-facing action.
