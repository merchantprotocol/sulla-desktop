# Sieve

Sieve turns a crowded inbox into a short owner queue, grouped handoffs, scheduling options, and unsent reply drafts. It goes beyond the basic daily inbox brief while preserving mailbox state.

## Setup
Connect an email integration with read access. Draft access and Calendar read access are optional. Pasted messages or a bounded CSV export are supported fallbacks.

## Use and customize
Ask Sulla to “sieve my inbox” and give a time range. Customize categories and urgency rules in `SKILL.md`. Sending, filing, archiving, deleting, label changes, and calendar writes always require explicit approval.
