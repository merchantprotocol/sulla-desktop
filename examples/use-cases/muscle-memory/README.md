# Muscle Memory

Muscle Memory turns tribal knowledge into a precise operational runbook with failure handling and rollback.

## Setup
No integration is required. Files is the canonical deliverable store; Secretary Mode transcripts, pasted notes, and uploaded documents are supported. Docker is optional for isolated dry-runs.

## Use and customize
Ask Sulla to create or update a runbook for a named process. Customize the required sections, escalation policy, and review cadence for your operation. External publication remains a human-approved step.
