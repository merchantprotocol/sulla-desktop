# Fireline

Fireline keeps an incident factual and coordinated from first alert through a blameless postmortem.

## Setup
No integration is required: paste an alert or upload logs. Docker logs, GitHub deploy context, Slack drafts, and owner notifications are optional. Files stores source-linked reports.

## Use and customize
Ask for `new`, `update`, or `postmortem`. Customize severity thresholds, update cadence, roles, and postmortem action-item fields. Slack status posts are always drafted and approval-gated.
