# Clausewise

**Listing:** Clausewise — *Know what you're signing before you sign it* — Review contracts in plain English, surface negotiation risks, and stage a redline without giving legal advice.

Clausewise reviews contracts from an upload, pasted text, Files, or an explicitly named Drive folder. It creates source-linked findings and negotiation language; it never signs, sends, or edits the original.

## Setup
No integration is required. Optionally connect Google Drive with `vault` if contracts live there. Keep legal documents in a human-approved Files folder. An attorney remains the decision-maker.

## Use and customize
Ask “Review this contract and flag what I should push back on.” Customize the risk categories and preferred negotiation posture in this skill. Save any requested review under an existing Files folder.
