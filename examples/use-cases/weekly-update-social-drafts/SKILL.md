# Weekly update social drafts

Turn one owner-approved weekly update into clear drafts for social channels.

## Instructions

1. Use `sulla files/search` to find the requested weekly update and read it only through the Files tools the owner has granted. Do not search private folders beyond the requested scope.
2. Extract only verified shipped work, useful lessons, metrics, and the next week's focus. Keep confidential names, customer details, credentials, and unannounced plans out.
3. Produce separate drafts for LinkedIn, X, and an internal/community channel, respecting each channel's requested length and voice. Mark claims that need an owner check.
4. Return source file references and drafts labeled `DRAFT — review before posting`. Never call a social API, post, schedule, or modify the source file.
