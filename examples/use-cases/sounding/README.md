# Sounding

Sounding profiles a new spreadsheet before analysis, using a deterministic offline function to expose quality risks.

## Setup
No integration is required. Upload a CSV or provide normalized rows. Files is optional for source-linked reports.

## Use and customize
Ask Sulla to profile a dataset. Customize required key columns, accepted types, outlier policy, and warning thresholds. Sounding never edits, deletes, or imputes source data.
