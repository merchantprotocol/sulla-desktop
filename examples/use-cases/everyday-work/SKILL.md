# Everyday work

This optional memory pack teaches Sulla how to handle common everyday jobs end to end: research and cited briefs, public web data, analysis, email triage and drafts, marketing content, images and video, business routines, business-idea evaluation, site deployment, and browser extensions. Each included skill explains when to use it, exact catalog commands, checks, cleanup, and safety traps.

## Install
Install this Use Case as a skill. Its `memory/manifest.json`, subject, and skills are loaded into memory with the pack. Installing is idempotent; uninstalling removes this pack's active memory and restores any lower-precedence seeded skill it overrode.

## Customize
After installing, edit the files in `Use Cases/skills/everyday-work/memory/`: change the subject facts and rules or tailor a skill's triggers and steps. Publish the edited Use Case through Files/Decide. The installed pack re-syncs from the published files; bump `memory/manifest.json` when changing the pack.
