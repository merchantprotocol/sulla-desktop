# Chartroom

**Listing:** Chartroom — *Turn a CSV into a shareable dashboard* — Build a self-contained, filterable HTML dashboard from a CSV or read-only query.

Chartroom turns a CSV, pasted table, or optional read-only PostgreSQL result into one browser-ready HTML dashboard. It verifies the metrics, embeds the data, adds coordinated filters and charts, and saves the finished report in Files.

## Setup
No integration is required. Put the source CSV in Files or paste a small table. A vault-backed PostgreSQL integration is optional and should be read-only.

## Use and customize
Ask Chartroom for the audience, decision, metrics, and dimensions that matter. Customize the dashboard's colors, chart mix, definitions, and filters in the generated HTML. Keep the source note, as-of date, accessible labels, and reconciliation checks. Sharing a public link always waits for human approval.
