# Horizon Line

See every renewal coming 90 days out.

## Setup
Put a contract register CSV/XLSX in Files, or connect a read-only CRM through vault. Calendar access is optional; reminder creation is approval-gated.

## Use and customize
Run the skill for an on-demand radar or enable the weekly `routine.yaml`. Customize the 90-day window, urgency thresholds, and output folder in `SKILL.md`.
