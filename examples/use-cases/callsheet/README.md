# Callsheet

Callsheet creates a complete hiring packet, then screens applications only against its stated rubric.

## Setup
No integration is required. Keep applicant files in Sulla Files. Browser research, email read/drafts, and calendar availability are optional; uploaded resumes and pasted inputs are the fallback. Memory stores editable role scorecards.

## Use and customize
Ask Sulla to write a job post, build an interview guide, screen applications, or draft candidate replies. Customize the scorecard subjects under `memory/subjects/`. Hiring decisions, postings, payroll, offers, messages, and invites remain human-approved.
