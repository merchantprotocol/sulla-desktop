# Dossier

Prepare a sourced pre-call brief from calendar, public web research, and prior transcripts.

## Setup
- Calendar read access is enough.
- Secretary Mode or Capture transcripts improve the brief; pasted notes work.
- CRM is optional and never written automatically.

## Use and customize
Ask “prep me for my call with [company]”. Set the calendar scope, research domains, output folder, and preferred brief length. Review source links and hypotheses before using them in a meeting.
