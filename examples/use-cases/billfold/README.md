# Billfold

Billfold turns bill documents into a reviewed, cash-checked payment run. It deliberately stops before payment so the human approves the exact spend.

## Setup
Connect a read-only ledger and optional mail/Drive source, or upload bills and a cash export to Files. No payment integration is required.

## Use and customize
Ask for this week's bills or upload a bill folder. Customize coding rules, due-date priorities, and the review folder. Approve coding and payment as separate decisions.
