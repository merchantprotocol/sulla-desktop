# Keel

Keel maintains one human-owned `TASKS.md` in Sulla Files for commitments, waiting items, someday ideas, and completed work.

## Setup
No integration is required. Optionally connect Calendar for read-only due-date context. Choose an existing Files folder; Keel searches before creating.

## Use and customize
Ask for your plate, add a task, complete a task, or extract explicit commitments. Customize section names and task detail conventions while keeping the four core sections.
