# Bidsmith

Turn a discovery call into a priced proposal draft with traceable evidence.

## Setup
- Connect Secretary Mode or Capture if available; otherwise provide a transcript or notes.
- Store approved pricing and templates in Files.
- Optional: connect e-signature or CRM only for a later, approved handoff.

## Use and customize
Ask “draft a proposal from this call.” Set currency, pricing rules, proposal sections, and the output folder. Review the evidence ledger and exact terms before sending. The included function renders deterministic Markdown; replace it with an approved DOCX/PDF renderer if one is installed.

The folder also includes `function.yaml` and `main.py` for the offline proposal renderer.
