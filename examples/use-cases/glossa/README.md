# Glossa

Glossa is an editable memory pack for names, acronyms, project codenames, and shorthand. It asks instead of guessing and keeps sensitive data out.

## Setup
No integration is required. Approve entries as they arise, and optionally keep a human-facing glossary in Files.

## Use and customize
Say “remember that X means Y in this context” or “what does X mean?” Edit subjects and skills in the pack, then sync it. Remove entries that are no longer true.
