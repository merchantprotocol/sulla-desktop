# First Light

First Light produces one short Monday brief with cash, sales, pipeline, the week's calendar shape, open commitments, risks, and one priority. It works with any subset of sources and names missing data once instead of failing.

## Setup
Connect only the sources you want read: Calendar, an email account, a ledger/payments account, a CRM, or Slack for optional owner-approved posting. Every business-data integration is optional; CSV and pasted figures are supported fallbacks.

## Use and customize
Import the workflow, set its timezone, and adjust the Monday time or source priorities. The workflow saves the brief to Files and sends an internal notification. It never posts or sends externally without a separate human Approve for the exact content and destination.
