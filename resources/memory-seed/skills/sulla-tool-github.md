**When:** Use `exec` to dispatch an exact `sulla github/<tool>` command. Discover current tools with `sulla meta/browse_tools '{"category":"github"}'` before an unfamiliar call.

For complete jobs, use `sulla-ship-a-code-change` to implement and open a PR, or `sulla-review-and-merge-prs` to review, resolve conflicts, order merges and prepare a release.

**Tools:**

- `sulla github/git_conflicts '{"absolutePath":"<absolutePath>"}'`: List files with merge conflicts and show the conflict diffs for each file. Required: absolutePath. Optional: none.
- `sulla github/git_diff '{"absolutePath":"<absolutePath>"}'`: Show changes between working tree, staging area, or commits. Required: absolutePath. Optional: staged, commitA, commitB, filePath.

- `sulla github/git_pull '{"absolutePath":"<absolutePath>"}'`: Pull commits from a remote repository. Automatically reports any merge conflicts after pull. Required: absolutePath. Optional: remote, branch.

**Do:**
1. Create a branch with `sulla github/git_branch '{"absolutePath":"<repo>","action":"create","branchName":"<branch>"}'`.
2. Stage and commit with `sulla github/git_commit '{"absolutePath":"<repo>","message":"<message>"}'`.
3. Push with `sulla github/git_push '{"absolutePath":"<repo>","branch":"<branch>"}'`.
4. Open a PR with `sulla github/create_pr '{"owner":"<owner>","repo":"<repo>","title":"<title>","head":"<branch>"}'`.
5. Check CI with `sulla github/check_runs '{"owner":"<owner>","repo":"<repo>","ref":"<head SHA>"}'` and merge only after verifying the expected head SHA with `sulla github/get_pr '{"owner":"<owner>","repo":"<repo>","pull_number":1}'`.
6. Review files with `sulla github/get_pr_files '{"owner":"<owner>","repo":"<repo>","pull_number":1}'`; clean a worktree with `sulla github/git_worktree '{"absolutePath":"<repo>","action":"remove","worktreePath":"<worktree>"}'` then `..."action":"prune"`.

**Don't:**
- Don't merge, close, delete refs, or publish releases without the required confirmation flag.
- Don't trust a stale PR head; re-read the PR and compare the SHA before merging.
- Don't use raw authenticated git network commands when the GitHub tools provide the operation.
