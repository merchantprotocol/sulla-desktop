trigger_phrases: [agent, specialist agent, agent manifest]

**Do:**
1. Create the agent in the Agents area and configure its soul, model, and tool policy.
2. Export its `sulla/v3` manifest for review.
3. Keep the agent local: the marketplace does not currently publish agent artifacts.
4. Request publication only for supported bundled use-case kinds and wait for Decide approval.
