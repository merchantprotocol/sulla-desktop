# Knowledge Base

Projects live in Sulla Files under `Sulla/Projects/<project-slug>/`. Each project folder has PROJECT.md (goal, status, owner agent, links) and TASKS.md (a markdown checklist: `- [ ] task — owner — note`; tick `- [x]` when done). Put plans, specs and notes in that folder too. Edit them with normal tools on the mount at `/mnt/sulla-files/Sulla/Projects/<project-slug>/`. Use `sulla files/search` to find projects. Create a new project folder only when the work is a real multi-session goal and no existing project fits. Never keep a separate task list anywhere else.

The former Projects row store is retired on Desktop. Existing database tables are retained only for historical data; do not write them.
